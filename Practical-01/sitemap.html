Practical 1: StudentHub Sitemap & Navigation Architecture

This sitemap visualizes the information architecture and navigation hierarchy of the StudentHub portal across guest, student, and admin user journeys.

Home Page (index.html) Global Entry Point & Welcome Hub

Module-Wise Page Breakdown

1. Public Information

  • index.html: Hero banner, quick facts, announcements
  • about.html: University overview, mission, faculty directory
  • faq.html: Interactive collapsible FAQ accordion
  • contact.html: Campus address, contact info, enquiry form

2. Authentication

  • register.html: Student registration with live regex validation
  • login.html: Role-based login (Student / Admin)
  • logout.php: Session destruction & redirect

3. Student Portal

  • dashboard.html: Student stats, quick notifications
  • profile.html: Student profile details and course info
  • feedback.html: Student campus feedback form

4. Campus Events

  • events.html: Public events listing with category filters
  • event_details.html: Individual event poster, venue, date
  • ajax_events.html: Live Fetch-API driven events list

5. Admin Panel Restricted

  • admin.html: Admin overview, metrics, student/event counters
  • students_manage.php: Full Student CRUD (Search/Filter)
  • events_manage.php: Event CRUD with poster file upload
  • audit_logs.php: Admin action history log
